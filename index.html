⌨️ Phím tắt & Hướng dẫn Game

Game hỗ trợ đầy đủ thao tác bàn phím tiện lợi:

  • Phím 1, 2, 3, 4 hoặc A, B, C, D: Chọn đáp án tương ứng
  • Phím Enter: Chuyển sang câu tiếp theo
  • Phím Space (Cách): Bật phát âm thanh Web Speech / Nghe lại câu hỏi
  • Phím ~ (hoặc `): Bật/Tắt cửa sổ điều tra SOC Terminal & Wireshark
  • Phím V: Kích hoạt nhận diện giọng nói (Web Speech Recognition)
  • Phím S: Bật / Tắt hiệu ứng âm thanh Web Audio
  • Phím T: Chuyển đổi giao diện Sáng / Tối (Dark/Light mode)
  • Phím Esc: Đóng bảng thông báo / modal
