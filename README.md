# 🛡️ TOEIC Quest: Cyber Office

Ứng dụng ôn thi TOEIC tương tác phong cách An ninh mạng dành cho sinh viên và kỹ sư công nghệ thông tin.

## 🚀 Tính năng chính
- **Placement Check**: Đánh giá năng lực đầu vào và ước tính điểm TOEIC 10–990.
- **Daily Mission**: 10 câu hỏi nhiệm vụ hàng ngày được tối ưu bằng Spaced Repetition.
- **Part 1 & 2 Listening**: Mô phỏng tranh SVG, Web Speech API hỗ trợ 3 giọng (Mỹ, Anh, Úc) và tùy chỉnh tốc độ.
- **Part 5 & 7 Training**: Luyện câu ngắn và bài đọc hiểu văn bản nội bộ.
- **Trap Hunter**: Chuyên đề săn 5 nhóm bẫy kinh điển trong đề thi ETS.
- **Weekly Boss Fight**: Màn đấu trùm mô phỏng xử lý sự cố Zero-Day Ransomware để thăng cấp CISO.
- **Vocabulary Arena**: Học từ vựng với hệ thống Leitner 5 hộp.
- **Error Notebook**: Sổ tay tự động lưu và ôn tập các câu từng làm sai.

## 💻 Công nghệ
- HTML5, CSS3 (Dark/Light mode).
- Vanilla JavaScript thuần, 100% không phụ thuộc thư viện ngoài.
- Web Audio API (tổng hợp âm thanh) & Web Speech API (Text-to-Speech).
- HTML5 Canvas vẽ biểu đồ kỹ năng.
